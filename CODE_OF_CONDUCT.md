# Code Of Conduct

## Scope

This policy applies only to GitHub issues, pull requests, discussions, and
feedback templates for this repository. It does not create a broader community
program, chat server, event policy, or support commitment.

## Expected Conduct

Keep participation practical and reviewable:

- stay on the first-release scope for the issue, pull request, discussion, or
  feedback template;
- describe evidence, commands, files, and behavior concretely;
- preserve security redaction and private-reporting boundaries;
- avoid personal attacks, harassment, discriminatory language, or repeated
  off-topic pressure;
- do not use public threads to disclose vulnerabilities or private dogfood
  evidence.

## Enforcement

Maintainers may edit titles for clarity, ask for missing evidence, move a report
to a safer channel, close off-scope discussions, lock threads, hide comments, or
block accounts when behavior prevents focused review.

Enforcement is limited to repository GitHub surfaces and is intended to protect
the trust loop, security reporting path, and maintainers' review time. It does
not imply broader community moderation infrastructure.
